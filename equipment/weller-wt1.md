# Weller WT 1 soldering station

- **Model:** WT 1 power unit, 120 V, 60 Hz, 95 W, fuse T 1.0 A. Serial T0053434298
  (label on the base, photographed 2026-09-29).
- **Irons it takes:** WTP 90, WP 80, WSP 80 (quick start, p.2).
- **Manuals:**
  - [Quick start (weller-tools.com)](https://www.weller-tools.com/sites/default/files/products/documents/WE_WT1_WT1H_ManualQuickStartT0055741501.pdf):
    mostly pictures, 29 languages.
  - [Supplementary operating instructions (ManualsLib)](https://www.manualslib.com/manual/1918145/Weller-Wt-1.html):
    English starts p.8. The full text of every procedure below is here.

## Front panel

Four buttons under the display, left to right: **Exit**, **▼**, **▲**, **Menu**.

## Set the temperature

From the main display, press ▲ or ▼ (quick start, p.5). This does nothing while the lock
symbol shows.

| Job | Setting | Basis |
|---|---|---|
| Brass heat-set inserts in PETG | about 450 °F (230 °C), range 430–480 °F | General practice for PETG; Weller gives no figure. Adjust to what seats cleanly |
| Solder | 650 °F as found on 2026-09-29 | Display, locked |

## The lock (padlock symbol on the display)

Locked, the station refuses every settings change until it is unlocked (supplementary, p.11).

**Unlock:**
1. Press **Menu**. "ON" appears.
2. Set the three-digit code with ▲/▼.
3. Press **Menu** to confirm. The padlock disappears.

**Lock:** in the menu, choose LOCK, set a three-digit code of your choice (001–999), and
confirm with **Menu** (p.11).

- **There is no default code.** Whoever locked the station chose it. Get it from them.
- **Forgotten code:** the manual's only instruction is to contact Weller customer service,
  technical-service@weller-tools.com (p.11).
- **Factory reset:** hold **Exit + ▲ + ▼** for three seconds while switching the station on
  (p.15). The manual does not say whether a reset clears the lock. Untested.
- **Where the code lives:** with Jared, off this repo. If you set a new one, tell him.

## Window function (related to the lock)

With the station locked, WINDOW can allow a ±1–99 °C (±1–180 °F) adjustment around the
locked temperature, so students can adjust within a range without unlocking (p.11). Off from
the factory.
